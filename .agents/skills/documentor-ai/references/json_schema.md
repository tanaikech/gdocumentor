# gdocumentor (DocuMentor AI) — CLI & Agent Skill JSON I/O Schema Reference

When invoked with `--json` or `--input-json`, `gdocumentor` guarantees strict stream separation:
- **`stdout`**: Contains **ONLY** a single valid JSON object (`CLIOutput` on success, or `{"success": false, "error": "..."}` on failure).
- **`stderr`**: Receives any diagnostic/error messages; progress spinners are disabled.
